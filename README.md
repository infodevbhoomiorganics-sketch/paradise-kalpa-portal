# Paradise Kalpa Portal

Build a premium, modern, visually stunning boutique Himalayan homestay website for Paradise Homestay Kalpa.

Details:
- Location: Rakpa, House No. 56, Kalpa, Saryo, Himachal Pradesh 172108
- WhatsApp/Phone: +91 82198 86774
- Rating: 4.9/5 (71 reviews)
- Pricing: Starting around ₹2,309/night (season dependent)
- Pages required: Home, Rooms/Stay, About, Dining, Amenities, Gallery, Location & Contact.

CRITICAL IMAGE RULE:
- Do NOT use placeholder images, external URLs, or stock photos.
- Import and use the uploaded real photos from the assets folder directly throughout the site (exterior building, wooden mountain-view bedroom, clean bathroom with geyser, panoramic balcony with prayer flags and Kinner Kailash snow peaks, morning tea view, Kinnaur apple orchard).

Features:
- Home: Cinematic hero ("Stay Above the Mountains at Paradise Homestay Kalpa"), WhatsApp booking CTAs, mountain & valley view highlights, authentic homemade Kinnauri food showcase, warm hospitality, guest reviews, Kalpa/Kinnaur attractions, final booking CTA.
- Rooms/Stay: Showcase the wooden mountain-view rooms, amenities, clean attached baths, and valley panoramas using only real photos.
- Dining: Fresh homemade Himachali & Kinnauri meals, farm/orchard freshness.
- Amenities: Free Wi-Fi, Parking, Hot Water/Geyser, Room Service, Smoke-Free, Mountain View Balconies.
- Gallery: Interactive masonry grid with lightbox zoom using only the uploaded assets.
- Location & Contact: Full address, interactive Google Maps embed for Paradise Homestay Kalpa / Rakpa, Get Directions, and direct WhatsApp contact.
- WhatsApp: All booking/enquiry buttons trigger WhatsApp to +91 82198 86774 with prefilled enquiry messages.
- SEO: Metadata, OpenGraph, LocalBusiness/Lodging schema, canonicals, sitemap, and robots for Kalpa homestay keywords.

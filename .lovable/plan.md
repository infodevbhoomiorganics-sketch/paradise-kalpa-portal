# Paradise Homestay Kalpa website

## Build
- Create a premium, image-led Himalayan visual system using the supplied property photos only.
- Add shared navigation, mobile menu, footer, and consistent WhatsApp booking actions.
- Build dedicated Home, Rooms / Stay, About, Dining, Amenities, Gallery, and Location & Contact pages.
- Add an interactive gallery lightbox, review and attraction content, and a location map with directions.

## Content and trust
- Use the supplied address, phone, rating, review count, and seasonal starting rate.
- Present authentic property details without inventing policies, room inventory, or unsupported claims.

## Search and sharing
- Add unique metadata and canonical links for each page.
- Add lodging and local-business structured data, crawler rules, and a sitemap covering every public page.

## Technical details
- Store the uploaded photos as project CDN assets and reference those assets throughout the site.
- Use TanStack routes for every major page and semantic design tokens for all styling.
- Validate the finished pages at desktop and mobile sizes, including navigation, gallery, maps, and WhatsApp links.
